# harnesses/admin/

This folder contains admin-level harnesses.

**v1 policy:** Admin harnesses live in this folder within the main repo.

**Future policy:** When security or client isolation requires it, admin harnesses may be moved to a separate private repo.

Admin harnesses have `mode: admin` and may modify harness definitions, permissions, and repo structure. They should be treated with extra review care.
