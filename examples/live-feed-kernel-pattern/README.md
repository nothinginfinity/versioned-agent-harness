## Example: live-feed-kernel pattern

This example shows how Versioned Agent Harness can support feed-driven products.

## Pattern
- A domain kernel defines how an LLM interprets a feed.
- RSS or live data sources provide input.
- Schemas define normalized items and processed items.
- The LLM generates summaries, indexes, alerts, and artifacts.
- A website or API publishes the output.

## Lesson
A domain-specific harness can turn the same engine into many products: PodcastPulse, DealScout, SportsBrief, WeatherDesk, and more.
