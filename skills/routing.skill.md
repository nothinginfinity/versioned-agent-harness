## Skill: Routing
*version: 0.1 | status: draft*

---

## Purpose
Route work to the correct agent, inbox, spec, or bulletin surface.

---

## Trigger Conditions
Load this skill when the task includes:
- route this
- who should handle this
- send this to
- create a bulletin
- create an inbox message

---

## Routing Rules
- Builder work goes to builder agents.
- Review work goes to reviewer agents.
- Read-only thinking goes to brainstorm agents.
- Cross-agent status updates go to bulletin surfaces.
- Direct tasks go to inbox surfaces.
- Agent-to-agent replies go to mail surfaces.
