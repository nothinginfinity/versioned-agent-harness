## Skill: Code Review
*version: 0.1 | status: draft*

---

## Purpose
Review code, specs, or diffs for correctness, maintainability, and risk.

---

## Trigger Conditions
Load this skill when the task includes:
- review code
- check this PR
- audit this
- inspect the diff
- find risks

---

## Output Format
Use this structure:
1. Summary
2. Blocking Issues
3. Non-blocking Suggestions
4. Questions
5. Recommendation

---

## Quality Checks
- Separate facts from guesses.
- Cite exact files or sections when possible.
- Do not overstate certainty.
- Prefer concrete fixes.
