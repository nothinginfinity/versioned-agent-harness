## Implementation Notes

## Recommended Storage
Start with Markdown and JSON files in GitHub.

## Recommended Naming
- `.harness.md` for harness files
- `.skill.md` for skill files
- `brain.json` or `memory.json` for memory
- `bulletin.md` for observer delta feeds
- `inbox.md`, `mail.md`, and `outbox.md` for communication surfaces

## Recommended Rules
- Use full repo paths in `ref:` fields.
- Keep bulletins short.
- Lazy-load skills only when triggered.
- Preserve changelogs.
- Separate read-only and write-capable agents.
- Prefer simple files before complex infrastructure.
