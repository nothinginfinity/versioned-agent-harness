## Glossary

## Harness
The full operating envelope around an LLM agent, including boot instructions, skills, memory, permissions, communication surfaces, and audit rules.

## Boot file
The startup instruction file that defines who the agent is and what it must read or obey.

## Skill
A focused instruction module loaded only when a task requires it.

## Memory
Durable compressed project or agent state.

## Bulletin
A short delta-feed entry for read-only observers or brainstorm agents.

## Inbox
A structured surface for incoming tasks.

## Outbox
A structured surface for outbound messages.

## Audit trail
The Git history, changelog, turn logs, and message status trail showing how behavior and work changed.
