## Product Model

Versioned Agent Harness can support several product models:

## 1. Custom Business AI Assistants
Build company-specific harnesses for sales, support, operations, research, or engineering.

## 2. Project AI Workspaces
Each project gets its own harness, memory, inboxes, specs, and skills.

## 3. Human Collaborator Kits
Give contractors or team members a project-specific LLM harness so their assistant follows the same workflow.

## 4. Data / Knowledge Agents
Connect a harnessed agent to feeds, documents, drives, or datasets.

## 5. Read-Only Audit Agents
Allow stakeholders to inspect, critique, and understand work without write access.
